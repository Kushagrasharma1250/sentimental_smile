
# sentimental_smile
This project is a web-based sentiment analysis platform designed to analyze comments from YouTube and Twitter. It provides users with insights into the emotional tone of social media discussions by leveraging state-of-the-art NLP models. The application includes a secure login and registration system, ensuring personalized access and data handling.
